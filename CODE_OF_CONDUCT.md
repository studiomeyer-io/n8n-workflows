# Code of Conduct

## Our pledge

We want this repository to be a place where builders ship better workflows. That requires an environment where contributors of all backgrounds, skill levels, and time zones can show up, ask questions, and have technical disagreements without it turning personal.

## Our standards

Examples of behavior that build trust:

- Direct, technical, helpful communication.
- Acknowledging when a contribution is solid or when feedback is correct.
- Linking to documentation, not just opinions.
- Asking clarifying questions before assuming bad faith.
- Reviewing pull requests with concrete suggestions.

Examples of behavior we will not accept:

- Insults, slurs, or harassment of any kind.
- Public personal attacks (technical disagreement is fine, personal attack is not).
- Sustained derailing of issues or pull requests.
- Publishing other contributors' private information without explicit permission.
- Sexualized language or imagery in any project space.

## Scope

This applies in any project space (issues, PRs, discussions, commit messages, code comments) and in public when an individual is representing the project (conferences, social media posts that link this repo, etc).

## Enforcement

Project maintainers are responsible for clarifying standards and may take corrective action including warning, temporary ban, or permanent ban from contribution.

If you see behavior that violates this code, contact the maintainers at **hello@studiomeyer.io**. Reports will be reviewed promptly and confidentially.
